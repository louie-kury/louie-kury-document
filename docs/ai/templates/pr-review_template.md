# PR 리뷰 템플릿

아래 양식을 GitHub PR 리뷰 본문에 복사한다. 권장 요청에는 머지 전에 반드시 수정해야 할 사항을 적고 **Request changes**로 제출한다. 참고 요청에는 지금 수정할 필요가 없고 머지를 막지 않는 발견 사항을 적는다. 참고 요청만 있으면 리뷰 결과에 따라 **Comment** 또는 **Approve**를 선택한다.

```markdown
<!-- 실제 리뷰 본문은 존댓말로 작성합니다. -->

## 권장 요청
<!-- 머지 전에 반드시 수정해야 할 사항의 위치, 영향, 기대 결과를 작성합니다. -->

## 참고 요청
<!-- 발견한 문제와 당장 수정하지 않아도 되는 이유를 작성합니다. -->
```

재리뷰에서는 이전 권장 요청이 최신 변경에 반영됐는지 먼저 확인한다. Approve는 리뷰를 한 팀원이 제출한다.
