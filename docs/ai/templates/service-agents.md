# 서비스 레포 작업 규칙

<!-- 프론트엔드 또는 백엔드 레포 루트에 AGENTS.md로 복사하고 공통 문서 경로를 실제 클론 이름에 맞춘다. -->

- 공통 문서는 서비스 레포 루트 기준 `../louie-kury-document/docs/`에 있다.
- 개발 전 공통 문서의 `ai/ROUTING.md`에서 작업에 해당하는 자료를 찾는다. 역할 배정이나 단계 판단이 필요하면 `ai/WORKFLOW.md`의 해당 절을 확인한다.
- 이슈·브랜치·커밋·PR을 작성·검토할 때 공통 문서의 `convension/GIT_CONVENTIONS.md`를 따른다. 커밋 직전 제목·본문의 변경 설명을 한국어로 확인하고, 게시한 PR의 완료 이슈 `Closes` 문구와 실제 대상 브랜치를 확인한다.
- 문서는 필요한 절만 읽고 공통 문서의 `ai/WORKFLOW.md`에 있는 컨텍스트·검증 비용 관리 기준을 따른다. 같은 작업의 수정 담당자를 재사용하고, 리뷰·QA의 독립성과 필수 검증은 유지한다.
